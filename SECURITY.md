# Security Policy

## Supported version

Security fixes target the current `main` branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting form if it is available for this repository. If it is not available, open a minimal public issue asking the maintainer to establish a private contact channel. Do not include exploit details, credentials, personal data, or sensitive URLs in a public issue.

Include the affected revision, impact, reproduction prerequisites, and a proposed mitigation when possible.

## Scope notes

RevisionLedger is a library vertical slice, not a hosted production service. Reports about provenance verification, SQL/query safety, fixture integrity, dependency supply chain, or CI privilege boundaries are in scope. Never submit real secrets or regulated data as a proof of concept.
